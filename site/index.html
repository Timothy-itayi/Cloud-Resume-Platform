Case study

Cloud Resume Platform

A static, accessible portfolio that proves cloud-engineering habits without dragging a backend, a framework, or a vendor SDK into the frontend. The site is the artifact: markup, layout, and deployment shape — not a screenshot of a console.

Problem
Most “cloud resume” demos couple the page to one provider’s runtime, counters, or auth. That makes the portfolio a product demo, not a portable engineering sample.
Approach
Semantic landmarks, skip link, keyboard-visible focus, and a responsive card layout. No build step. Personal data stays as placeholders. Hosting can be object storage, a static host, or a plain web server.
Constraints
HTML, CSS, and a small script only. No React, no Node toolchain, no database, no cloud-specific client libraries.
Status
Active — this homepage is the current revision.

Live Serverless / Azure / APIs

PitWall

Serverless Formula 1 dashboard on Azure, backed by historical OpenF1 data. The browser never calls OpenF1; visitors read a Function API that serves a private Blob cache.

  • Timer snapshot plus cache-aside race details in Blob Storage
  • Standalone Function App for the timer trigger, Static Web App on the Free SKU
  • OpenF1 calls paced and cached so page views do not burn the upstream budget
